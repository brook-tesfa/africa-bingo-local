# Windows releases

Windows installers are published on the repository's **Releases** page rather
than committed to Git. This avoids GitHub's 100 MB per-file repository limit.

The release workflow produces:

`Africa-Bingo-Local-Setup-4.1.0-x64.exe`

The installer contains the app only. Device activations, accounts, passwords,
balances, sales, and local databases are never included in a release artifact.
